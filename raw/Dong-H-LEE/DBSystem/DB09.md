#### Nested Queries

![](../images/20261109_dbsystem_db09_03.png)

- 하나의 완전한 형태의 select-from-where block이 다른 query의 `WHERE` clause 안에 존재하는 것.
- Query 안에 다른 Query가 있는 형태 → Inner, Outer Query가 존재.

![](../images/20261109_dbsystem_db09_04.png)

- 중첩 갯수의 제한을 두지 않음 →  여러번의 Nesting 허용함(allow multiple level)

  → Nested가 많다면 performance에 큰 영향을 미치므로 남발해서는 안됨.

- 모든 nested query는 펼칠 수 있음

![](../images/20261109_dbsystem_db09_05.png)

- Pnumber IN ( select - from - where ) or Pnumber IN ( select - from - where ) → 2가지의 nested query 중 하나라도 만족하는 Pnumber.

#### Comparison Operators

- IN operator

  ![](../images/20261109_dbsystem_db09_06.png)

  - IN : 어떤 value(v)와 어떤 집합(V) 간의 관계를 true / false로 알려주는 연산
  - TRUE : 어떤 value가 어떤 집합의 원소 중 하나일 때
- = ANY

  ![](../images/20261109_dbsystem_db09_07.png)

  - 그 value가 그 집합의 어떤 하나의 value와 값이 같다면 TRUE 반환
  - IN이랑 동일한 의미
  - = 대신 >, ≥, \<, ≤, and \<> 를 사용할 수 있음
- = ALL

  ![](../images/20261109_dbsystem_db09_08.png)

  - 그 value가 그 집합에 있는 모든 value랑 값이 같을 때 TRUE 반환
  - 마찬가지로 = 대신 >, ≥ , \< , ≤ , and \<> 사용 가능.

  ![](../images/20261109_dbsystem_db09_09.png)

  - 5번 department에서 일하는 모든 사람의 Salary 보다 Salary가 큰 사람의 이름

  ![](../images/20261109_dbsystem_db09_17.png)

  - `WHERE` 절 안에 explicit 한 value들을 만들어서 set을 만들고 그 set을 이용한 조건을 넣을 수 있다.

#### Aggregate Functions

![](../images/20261109_dbsystem_db09_23.png)

- SELECT의 결과는 tuple들의 집합(table)이 나옴.
- Aggregate function은 결과로 나온 여러 개의 tuple을 summarize해서 하나의 single-tuple로 보여주는 함수
- SQL에서는 COUNT, SUM, MAX, MIN, and AVG의 함수들을 기본적으로 제공함.
- 적용 대상은 result로 나온 tuple

![](../images/20261109_dbsystem_db09_24.png)

![](../images/20261109_dbsystem_db09_26.png)

#### Grouping

![](../images/20261109_dbsystem_db09_27.png)

- Query의 결과로 나오는 tuple들을 몇 개의 group으로 나누고, 각 group에 대해서 aggregate function을 적용한 결과를 보기 위함. → Group 별 summary tuple을 볼 수 있음.
- Grouping attributes  → grouping 하는 조건에 대한 속성

  → 결과로 나온 tuple 들을 grouping attribute가 같은 tuple끼리 grouping 하는 것.

  → `SELECT` 절에 반드시 포함되어야 함.

- 즉, 각 group은 같은 grouping attribute value를 가지는 Tuple들의 집합이 됨.
- `GROUP BY` 절을 이용해서 특정

![](../images/20261109_dbsystem_db09_28.png)

![](../images/20261109_dbsystem_db09_29.png)

#### HAVING clause

![](../images/20261109_dbsystem_db09_30.png)

- GROUP BY를 통해 나온 tuple의 group 중 조건을 걸어서 조건을 만족하는 그룹에 대한 summary를 보고 싶을 때 사용

![](../images/20261109_dbsystem_db09_31.png)

![](../images/20261109_dbsystem_db09_32.png)

![](../images/20261109_dbsystem_db09_33.png)

![](../images/20261109_dbsystem_db09_34.png)

- HAVING은 조건을 만족하는 GROUP에 대해서만 summary tuple을 보여줌.
- `WHERE`은 tuple에 관한 조건 clause이고 `HAVING`은 tuple들의 group에 관한 조건 clause

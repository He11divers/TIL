#### C constant review

![](../images/20261022_c_sw_week4_1_01.png)

→ const가 붙어있다면 단순 값 수정은 불가.

→ 그래도 변수니까 메모리에 할당되어 있으므로 주소에 접근하여 값을 수정하거나, type casting을 통해서 const를 해제하는 방식으로 값을 바꿀 수 있음.

→ Literal(constant) : 얘는 바꾸려면 실행파일을 바꾸는 등의 직접 변경을 통해서만 값을 바꿀 수 있음.

#### Pointer to Constant

![](../images/20261022_c_sw_week4_1_02.png)

```c
const int* ptr = &num; // ptr에는 num이 위치한 주소값이 const로 들어감.
// 포인터 변수인 ptr이 가리키는 주소의 값을 ptr을 통해서는 바꿀 수 없음
// 하지만 num 변수 자체는 const가 아니기 때문에 ㄱㅊ음
```

![](../images/20261022_c_sw_week4_1_03.png)

```c
int* const ptr = &num1; // 이 경우는 이야기가 달라짐.
// ptr의 메모리 공간 자체가 const가 됨.
// 즉 ptr이 가리키고 있는 주소를 바꿀 수 없다는 이야기.
// 다만 위와 다르게 *ptr을 통해 ptr이 가리키고 있는 메모리 주소의 값은 바꿀 수 있음
```

```c
// cin이 아니라 getline(cin, str)을 사용하면 단어가 아니라 문장 단위로 받을 수 있음.

#include <iostream>
#include <string>
using namespace std;

ing main(void) {
	string line;
	cout << "Write a line" << endl;
	while(getline(cin, line) {
		cout << line << "---" << endl;
	}
	return 0;
}

// getline(cin, str, ':')을 사용하면 ":"을 줄 바꿈 문자로 인식한다.
// 이건 좀 결과가 특이함.
#include <iostream>
#include <string>
using namespace std;

int main(void) {
	string line;
	cout << "write a line" << endl;
	while(getline(cin, line, ':') && line != "q") {
		cout << line << "---" << endl;
	}
	return 0;
}

사용자가 I:like:HY를 입력했을 때

like--- 까지만 출력하고 다음 사용자의 입력을 기다림.
사용자가 다시 I:love:my:son을 입력하면
HY---를 출력하고
I---
love--- 이렇게 이어서 출력함.
```

#### Function Overloading

![](../images/20261022_c_sw_week4_1_25.png)

- 이름이 같은 함수가 여러 개 있어도 각각 함수의 type이 다르면 compiler가 구별해서 compile 해줌.
- function type이란 명시적으로 return type 과 input type을 합친 것을 말함.

![](../images/20261022_c_sw_week4_1_26.png)

- function signature이란 function을 구분하는데에 사용되는 것.
  - return type은 function 구분에 사용되지 않아서 포함 x
  - 하지만 경우에 따라서는 return type이 포함될 수도 있음.
- 위 사진의 경우 return type은 다르지만 function name과 argument들의 type이 같다.
  - function signature가 같기 때문에 compile error가 발생

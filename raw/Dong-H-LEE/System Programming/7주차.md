#### 다차원 배열이랑 조금은 다른 Multi-Level Array

![](../images/20261016_system_programming_week7_13.png)

![](../images/20261016_system_programming_week7_14.png)

![](../images/20261016_system_programming_week7_15.png)

1. Nested Array를 사용하면 memory access를 줄일 수 있음.
    1. Multi-level array는 level 갯수만큼 memory access가 필요함.
    2. memory access는 많을 수록 성능이 많이 줄어듦.
2. Multi-level array를 사용하면 사용하지 않는 배열의 영역에 대해 할당을 하지 않을 수 있음.
    1. nested array는 일단 크기를 선언하기에 빈 영역이 할당되어 있을 수 있음.
    2. memory 사용 효율 측면에서 장점이 있음.

N x N 행렬은 선언한 배열 크기를 모두 사용함 → Multi-Dimension 행렬이 더 유리함.

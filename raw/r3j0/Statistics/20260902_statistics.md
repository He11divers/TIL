# 중심경향 측정치 (Measures of Central Tendency)
데이터 집합의 전체 분포가 어디에 집중되어 있는가? 에 대한 대표적인 통계값

- 평균 (Mean)
  - 모평균 ($\mu = \frac{\sum x_i}{N}$)
  - 표본평균 ($\bar{x} = \frac{\sum x_i}{n}$)
  - 이상 데이터에 민감함
- 중앙값 (Medium)
  - 모든 데이터를 전부 반영하진 않는다.
  - 이상 데이터에 둔감함 
- 최빈값 (Mode)
  - 여러 개가 존재하거나, 존재하지 않을 수도 있다.

# 산포도 측정치 (Measure of Dispersion)
데이터가 중심에서 얼마나 흩어져 있는지에 대한 지표

- 범위 (Range) : 최댓값과 최솟값의 차이
- 분산 (Variance) 
  - 모분산 ($\sigma^2 = \frac{\sum (x_i - \mu)^2}{N}$)
  - 표본분산 ($s^2 = \frac{\sum (x_i - \bar{x})^2}{n-1}$)
- 표준편차 (Standard Deviation)
  - 모표준편차 ($\sigma = \sqrt{\sigma^2}$)
  - 표본표준편차 ($s = \sqrt{s^2}$)
- 사분위수 (Quartiles)
  - 데이터를 4등분하는 3개의 지점 값 (Q1 (하위 25% 지점), Q2 (중간 지점), Q3 (상위 25% 지점))
- 사분위범위 (IQR)
  - 중앙 50% 데이터가 차지하는 범위 (Q3 - Q1)
  - 이상치의 하한과 상한을 구함으로써 이상치 탐지에 용이하다. (하한 : Q1 - 1.5 * IQR, 상한 : Q3 + 1.5 * IQR)
- 변이계수 (Coefficient of Variation)
  - 표준편차를 평균으로 나눈 값 (데이터의 흩어진 정도. 단위나 크기가 다른 두 개 이상 그룹을 비교할 때 사용)


## 표본분산을 n-1 로 나누는 이유
- n으로 나눌 시 모분산을 과소추정하는 편향이 발생하기 때문에, n-1 로 나누어 불편추정량을 얻는다. (n으로 나누면 편의추정량)
- 이를 베셀 수정 (Bessel's Correction) 이라고 한다.


# 분포의 형태 (Shape of Distribution)
- 왜도 (Skewness)
  - 데이터가 한 쪽으로 치우친 정도 (비대칭도)
  - (+) : 오른쪽 꼬리가 길고, 왼쪽에 데이터가 몰려 있다.
  - (-) : 왼쪽 꼬리가 길고, 오른쪽에 데이터가 몰려 있다.
- 첨도 (Kurtosis)
  - 분포의 뾰족한 정
  - 정규분포의 첨도 기준값은 3.
  - (+) (첨도 > 3, 초과첨도 > 0) : 뾰족한 모양. 중심에 데이터가 많이 몰려 있다.
  - (-) (첨도 < 3, 초과첨도 < 0) : 완만한 모양. 데이터가 넓게 퍼져 완만하다.

## Cargo

Rust의 공식 빌드 도구이자 패키지 매니저. 

```bash
$ cargo new hello

# 실행 시 Rust 프로젝트를 만들어 준다.

hello/
├── Cargo.toml # npm의 package.json
└── src/
    └── main.rs
```

```bash
$ cargo new my-app  # 새 Rust 프로젝트 생성   
$ cargo run         # 컴파일 + 실행
$ cargo build       # 컴파일
$ cargo check       # 실행 파일 생성 없이 컴파일 오류 검사
$ cargo test        # 테스트 실행
$ cargo add rand    # 의존성 추가
$ cargo build --release     # 최적화된, "배포용 빌드"
```

- Rust 에서는 그냥 `rustc main.rs` 로 직접 컴파일 할 수 있지만, 실제 프로젝트에서는 Cargo 로 중심으로 개발한다. 
- Cargo는 Rust 라이브러리 생태계인 crates.io 와 연결되어 있다. Rust에서는 패키지/라이브러리를 crate (크레이트) 라고 부른다.

```bash
rejo@rejo-mac practiceRust % cargo new hello
    Creating binary (application) `hello` package
note: see more `Cargo.toml` keys and their definitions at https://doc.rust-lang.org/cargo/reference/manifest.html
rejo@rejo-mac practiceRust % 
```

- `Cargo.toml` 의 내용
```toml
# 프로젝트 이름과 버전
[package] 
name = "hello"
version = "0.1.0"
edition = "2024"

[dependencies]
```


### num-bigint 크레이트 사용

1234의 5678 제곱은 매우 큰 수기 때문에 에러가 발생한다.

```rust
fn main() {
    let v: u128 = 1234;
    println!("{}", v.pow(5678));
}

/*
    thread 'main' (1858747) panicked at /rustc/88d9e12ae178fab0fb5cc050a94da85685d449ea/library/core/src/num/mod.rs:1351:5:
    attempt to exponentiate with overflow
    note: run with `RUST_BACKTRACE=1` environment variable to display a backtrace
-> 오버플로우가 발생하는 exp 시도
*/
```

num-bigint 크레이트를 기입해보자. Cargo.toml 에 크레이트 이름과 버전을 기입한다.

- `Cargo.toml`
```toml
[dependencies]
num-bigint = "0.4"
```

Cargo가 빌드할 때 creates.io 에서 해당 라이브러리를 자동으로 받아온다.

- `main.rs`
```rs
// num_bigint 크레이트 안에 있는 BigInt 타입을 사용하겠다.
use num_bigint::BigInt;
// 만약 use 가 없으면 매번 num_bigint::BigInt 라고 길게 써야 함.
// :: -> Rust 에서 경로 (Path) 를 따라 들어갈 때 쓰는 연산자

fn main() {
    let v = BigInt::from(1234);
    // from : From 이라는 trait 에서 제공되는 함수?
    //        어떤 타입을 받아서 BigInt 라는 타입으로 변환하게 하는..
    println!("{}", v.pow(5678));

    // :: -> 보통 타입, 모듈, 크레이트 등에 속한 항목에 접근할 때 쓴다
    // . -> 이미 존재하는 값 (instance) 의 메서드를 호출할 때 쓴다
}
```

### rand 크레이트 사용

- Cargo.toml
```toml
[package]
name = "dice"
version = "0.1.0"
edition = "2024"

[dependencies]
rand = "0.8.0"
```

```rs
use rand::Rng;
// rand 크레이트 안에 있는 Rng 라는 trait
// 왜 가져오냐? rng.gen_range 같은 메서드가 Rng trait에서 제공

fn main() {
    let mut rng = rand::thread_rng();
    // rand::thread_rng() : 현재 실행 중인 스레드에서 사용할
    //                      난수 생성기를 반환

    for _ in 0..5 {
        let dice = rng.gen_range(1..=6);
        println!("{}", dice);
    }
}
```

```rs
use rand::Rng;

// 상수 선언 : const 상수명: 타입 = 값;
const MAP_N: usize = 25;

fn main() {
    let mut rng = rand::thread_rng();

    // 2차원 배열 초기화
    // let mut 변수명 = [[초깃값; 배열 길이]; 배열 길이];
    let mut maze = [[0; MAP_N]; MAP_N];

    for n in 0..MAP_N {
        maze[n][0] = 1;
        maze[0][n] = 1;
        maze[n][MAP_N-1] = 1;
        maze[MAP_N-1][n] = 1;
    }

    for y in 2..MAP_N-2 {
        for x in 2..MAP_N-2 {
            if x % 2 == 1 || y % 2 == 1 { continue; }
            maze[y][x] = 1;
            let r = rng.gen_range(0..=3); 
            // match 표현식 {
            //  값 1 => 값 1 일때 처리
            //  값 2 => 값 2 일때 처리
            //  _ => 그 외 처리
            // }
            match r {
                0 => maze[y-1][x] = 1,
                1 => maze[y+1][x] = 1,
                2 => maze[y][x-1] = 1,
                3 => maze[y][x+1] = 1,
                _ => {},
            }
        }   
    }
    
    let tiles = ["□", "■"];
    for y in 0..MAP_N {
        for x in 0..MAP_N {
            print!("{}", tiles[maze[y][x]]);
        }
        println!("");
    }
}
```

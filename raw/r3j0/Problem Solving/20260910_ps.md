## 문제

종현이는 캠프장의 강의실에서 식당으로 가려고 한다. 캠프장은 가로 N칸, 세로 N칸의 격자로 되어 있으며, 몇몇 칸에는 장애물이 있어서 종현이가 갈 수 없다. 캠프장의 정보가 주어질 때, 종현이가 강의실에서 식당으로 가면서 항상 가는 곳을 구하는 프로그램을 작성하여라. 단, 한 격자에서 인접한 동, 서, 남, 북 네 격자로만 갈 수 있다.

## 입력

첫 번째 줄에는 캠프장의 크기 N (2≤N≤50)이 입력된다. 두 번째 줄에서 차례로 N개의 줄에는 각각의 격자에 대한 정보가 공백 없이 입력한다. 이 때, '.'은 빈 곳, '#'는 장애물, 'S'는 강의실, 'E'는 식당이다. 종현이가 강의실에서 식당으로 갈 수 없는 데이터는 들어오지 않는다.

## 출력

입력형식과 똑같이 출력하나 반드시 가는 곳을 'o'로 출력한다.

## 풀이

초기 아이디어는 다음과 같다.
1. 목적지에 도달할 수 있는 경로마다, 번호를 각각 생성해서 기억한 뒤, 그 경로들이 모두 지나는 칸만 o로 표시하면 naive 하게 풀이할 수 있겠지만 경우의 수가 너무 많다.
2. 격자 BFS가 아닌 그래프 관점으로 바라봤을 때, "무조건 지나는 칸" 은 그 칸이 없을 때 BFS가 성립하지 않는다. (그래프가 이어지지 않는다.)
3. 발상을 달리 해서, `.` 칸을 하나씩 장애물로 바꾸었을 떄 BFS가 성립하지 않는다면 "무조건 지나는 칸" 이다. N 최대 제한이 50이니 가능하다.

- 정답 / PyPy3 / 715ms / 79.9MB

```py
# 1277 : 반드시 가는 곳
import sys
from collections import deque
input = sys.stdin.readline

# naive 하게는,
# 목적지에 도착하는 경로의 번호를 생성해서 모두 기억해서
# 그 번호들이 지나는 칸 모두만 o로 표시하면 될텐데
# 경로가 너무 많음. 더 간단하게 할 순 없을까?

# 격자가 아닌, 그래프로 바라보면..
# 단절점과 단절선 느낌으로 해도 괜찮을텐데
# (해당 칸이 없으면 성립되지 않는 칸)

# 오히려 다른 발상으로? . 칸들을 하나씩 없앤 뒤에
# BFS가 하나라도 안 뜨면 그 칸이 진짜 아님? ㅋㅋ
# 어?

n = int(input().rstrip())
maps = [list(input().rstrip()) for _ in range(n)]
start = []
end = []
for i in range(n): 
    for j in range(n):
        if maps[i][j] == 'S': start = [i, j]
        if maps[i][j] == 'E': end = [i, j]

dy = [-1, 1, 0, 0]
dx = [0, 0, -1, 1]

def bfs():
    q = deque()
    q.append(list(start))
    vis = [[False for _ in range(n)] for _ in range(n)]
    vis[start[0]][start[1]] = True

    while q:
        now = q.popleft()
        if now == end:
            return False

        for d in range(4):
            ny = now[0] + dy[d]
            nx = now[1] + dx[d]

            if 0 > ny or ny >= n or 0 > nx or nx >= n or vis[ny][nx] or maps[ny][nx] == '#': continue
            q.append([ny, nx])
            vis[ny][nx] = True
        
    return True
    
ans = []
for i in range(n):
    for j in range(n):
        if maps[i][j] == '.':
            maps[i][j] = '#'
            if bfs():
                ans.append([i, j])
            maps[i][j] = '.'

for a in ans: maps[a[0]][a[1]] = 'o'

for m in maps: print(''.join(m))
```

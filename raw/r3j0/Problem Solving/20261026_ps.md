## 문제

N∗N 크기의 격자 바닥에 돗자리를 깔기 위해 나무가 없는 평평한 곳을 찾아야 한다.

나무는 총 T그루가 있으며, 나무는 한 격자 칸을 차지한다.

돗자리를 정사각형으로 가장 넓게 깔 때, 한 변의 길이를 구하라.


## 입력

첫 줄에 정수 N이 주어진다. (2≤N)

다음 줄에 양의 정수 T (T≤N^2)가 주어진다.

다음 T줄에 걸쳐 나무의 위치 행과 열이 공백을 구분으로 주어진다.

## 출력

가장 넓은 정사각형 돗자리의 한 변의 길이를 출력한다.

## 풀이

### 초기 아이디어 (T개의 나무마다 4방향 영역 분할)

초기에는 나무와 나무 사이의 최대 크기 직사각형 영역을 구해 그 안에서 최대 크기 정사각형 영역을 구하고자 했다.  

divide 함수를 구현하여 기준이 되는 나무에서 4방향으로 영역을 분할하고, 다른 나무에 의해 영역을 또 분할하면서, 무조건 처음 기준으로 잡았던 나무와 이웃하도록 조건을 추가했다. 결과적으로 한 나무를 기준으로 이웃한 최대 크기 직사각형 영역을 리스트로 얻어냈다.

T <= 10 에서는 정답을 받았지만, T <= 100 에서는 메모리 초과를 받았다. 메모리에 수많은 영역 정보가 생기는 것에 더불어 중복 탐색되어도 줄이지 못하는 것이 문제였다.

- 메모리 초과 / PyPy3 / 694ms / 192.0MB

```py
# 8014. 돗자리 깔기
import sys
input = sys.stdin.readline

# 기초 아이디어 : T끼리 브루트포스
# 다른 T 중 x나 y가 같지 않은 거 : 사이드 2개로 분할
# 다른 T 중 x나 y가 같은거 : 사이드 1개로 분할

n = int(input().rstrip())
t = int(input().rstrip())
trees = [list(map(int, input().rstrip().split())) for _ in range(t)]

ans = 1 if t > 0 else n

def divide(y, x, y1, x1, y2, x2, oy, ox):
    global ans
    areas = []

    # 위
    up = [y1, x1, y - 1, x2]
    if (up[2] - up[0] + 1 > ans and 
        (up[0] <= oy <= up[2] and (abs(up[1] - ox) == 1 or abs(up[3] - ox) == 1)) or
        (up[1] <= ox <= up[3] and (abs(up[0] - oy) == 1 or abs(up[2] - oy) == 1))): areas.append(up)

    # 아래
    down = [y + 1, x1, y2, x2]
    if (down[2] - down[0] + 1 > ans and 
        (down[0] <= oy <= down[2] and (abs(down[1] - ox) == 1 or abs(down[3] - ox) == 1)) or
        (down[1] <= ox <= down[3] and (abs(down[0] - oy) == 1 or abs(down[2] - oy) == 1))): areas.append(down)

    # 왼쪽
    left = [y1, x1, y2, x - 1]
    if (left[3] - left[1] + 1 > ans and 
        (left[0] <= oy <= left[2] and (abs(left[1] - ox) == 1 or abs(left[3] - ox) == 1)) or
        (left[1] <= ox <= left[3] and (abs(left[0] - oy) == 1 or abs(left[2] - oy) == 1))): areas.append(left)

    # 오른쪽
    right = [y1, x + 1, y2, x2]
    if (right[3] - right[1] + 1 > ans and 
        (right[0] <= oy <= right[2] and (abs(right[1] - ox) == 1 or abs(right[3] - ox) == 1)) or
        (right[1] <= ox <= right[3] and (abs(right[0] - oy) == 1 or abs(right[2] - oy) == 1))): areas.append(right)

    return areas

for i in range(1):
    # 1. 현재 t에 기반한 4방향 영역
    # 만약, 영역이 언더가 된다면 추가하지 않는다.
    areas = divide(trees[i][0], trees[i][1], 1, 1, n, n, trees[i][0], trees[i][1])

    # 2. 다른 t를 둘러보면서, 현재 영역에 기반해 분할하기
    # 만약, 현재 ans 보다 작아진다면 더 분할할 필요가 없다!!
    for j in range(t):
        if i == j: continue

        new_areas = []
        for a in areas:
            if a[0] <= trees[j][0] <= a[2] and a[1] <= trees[j][1] <= a[3]:
                new_areas.extend(divide(trees[j][0], trees[j][1], a[0], a[1], a[2], a[3], trees[i][0], trees[i][1]))
            else:
                new_areas.append(a)
        areas = new_areas

    # 3. 나눈 영역 기반 최대 정사각형 뽑기
    print(areas)
    for a in areas:
        ans = max(ans, min(a[2] - a[0] + 1, a[3] - a[1] + 1))

print(ans)
```

### AI 힌트 아이디어 ((T+1)^2 개 쌍의 시작점 후보부터 커팅)

최대 크기 정사각형으로 돗자리를 깔았을 때, 돗자리의 시작점을 어디로 잡을 지를 고민해보면 다음과 같다.
- 행 : 1 또는 어느 나무의 행 + 1
- 열 : 1 또는 어느 나무의 열 + 1

왜 1 또는 어느 나무의 좌표 + 1 일까? 최대 크기 돗자리를 깔았을 때, 돗자리를 **최대한 왼쪽이나 위쪽으로 옮겨보려고 한다면 벽이나 나무 앞에서 멈추기 때문이다.**

즉, 돗자리의 시작점 후보는 (101개) x (101개) 개 쌍이다.

시작점을 먼저 잡아놓고 다른 나무와 비교해서 영역을 커팅해 최소 영역을 구한다면, O(T^3) 으로 계산할 수 있다.

처음엔 DP 아이디어밖에 떠오르지 않았는데, 감명깊은 해결법이였다.

- 정답 / PyPy3 / 176ms / 82.8MB

```py
# 8014. 돗자리 깔기
import sys
input = sys.stdin.readline

# 다음 아이디어 ( ChatGPT 힌트 )
# 최대 크기 돗자리는 시작점이 다음 중 하나이다.
#  y : 1 또는 어느 나무의 행 + 1
#  x : 1 또는 어느 나무의 열 + 1
# 왜 이게 가능하냐? 최대 크기 돗자리를 깔았을 때
# "왼쪽이나 위쪽으로 최대한 이동 가능했을 때 나무나 벽에 부딪히기 때문에"

# 행 후보가 101개, 열 후보가 101개 이므로,
# 한 후보 쌍마다, 다른 나무 T와 비교하면서 돗자리 크기를 줄여나간다.

n = int(input().rstrip())
t = int(input().rstrip())
trees = [[0, 0]] + [list(map(int, input().rstrip().split())) for _ in range(t)]

ans = 1
for i in range(t+1):
    for j in range(t+1):
        start = [trees[i][0] + 1, trees[j][1] + 1]
        now_len = min(n - start[0] + 1, n - start[1] + 1)
        
        for k in range(1, t+1):
            if trees[k][0] >= start[0] and trees[k][1] >= start[1]:
                now_len = min(now_len, max(trees[k][0] - start[0], trees[k][1] - start[1]))
        
        ans = max(ans, now_len)

print(ans)
```

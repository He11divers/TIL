## 문제

좌우 한 줄로 있는 N개의 장소 각각에 조약돌이 몇 개씩 놓여 있다.

철수가 할 수 있는 작업의 종류는 아래 두 가지이다.

 
1. 인접한 두 장소에서 임의의 동일한 개수의 조약돌을 가져가기

2. 한 장소에서 임의의 개수의 조약돌을 가져가기

 
어떤 장소에 조약돌이 더 이상 없는 경우에도 그 장소는 그대로 남아 있어서, 

초기에 인접하지 않았던 두 장소가 인접한 것으로 바뀌지 않는다.

철수는 위의 두 작업 중 하나를 골라서 실행하는 것을 반복하여 모든 조약돌을 가져가려고 한다.

초기에 각 장소에 있는 조약돌들의 개수를 입력받아, 철수가 할 수 있는 최소의 작업 횟수를 계산하는 프로그램을 작성하라.


## 입력

첫 번째 줄에 장소의 개수 N이 주어진다.

두 번째 줄에 N개의 장소 각각에 있는 조약돌 개수가 왼쪽 장소에 해당하는 것부터 순서대로 공백 하나씩을 사이로 두고 주어진다.​ 

## 출력

첫 번째 줄에 답을 출력한다.

## 풀이

### 초기 아이디어 (그리디)

1. 테스트 케이스를 보며, 최대한 "인접한 이웃이 동일한 개수" 가 되도록 만들어야 한다는 것을 알게 되었다. 인접한 이웃이 동일한 개수가 되지 않는다면 그냥 한 장소에서 전부 가져간 것과 동일하다.
2. 인접한 이웃 장소를 동일한 개수만큼 가져간다면 필요 행동 횟수는 -1 회가 된다.
3. 인접한 이웃을 임의의 개수만큼 가져갈 때마다 남은 조약돌의 개수가 음수가 되면 안 된다.
```
2 5 7 4 일 때..

  0  3  7  4 (남은 조약돌 개수 : 3 (5 - 2))
  0  0  4  4 (남은 조약돌 개수 : 4 (7 - 3))
  0  0  0  0 (남은 조약돌 개수 : 0 (4 - 4))
-> 인접한 이웃을 임의의 개수만큼 가져갔을 때 0으로 만들 수 있는 구간!

7 5 9 3 일 때..

  2  0  9  3 (남은 조약돌 개수 : -2 (5 - 7))
-> 이는 곧 이웃한 공간에서 가져가고 임의의 공간에서 한번 더 가져가야 하는 구간이다!
탐색하면 안 된다.

```

4. 조약돌의 개수를 0으로 만들 수 있는 구간을 최적으로 구해냈다면, 한 줄에서 얼마나 많이 배치할 수 있는지 그리디 정렬을 통해 최대 구간 갯수를 구한다.
5. 임의의 공간에서 조약돌을 전부 가져가면 N 회, 0으로 만들 수 있는 구간이 있을 때마다 -1 회만큼 줄어드므로, 0으로 만들 수 있는 구간이 A 개 라면, 정답은 N - A 이다.

- 정답 / PyPy3 / 408ms / 75.2MB

```py
# 5122. 조약돌
import sys
input = sys.stdin.readline

n = int(input().rstrip())
arr = list(map(int, input().rstrip().split()))

order = []
for i in range(n-1):
    now = arr[i]
    for j in range(i+1, n):
        if now > arr[j]: break
        now = arr[j] - now

        if now == 0: 
            order.append([i, j])
            break

order.sort(key=lambda x:(x[1], x[0]))

now_s = -1
ans = n
for i in range(len(order)):
    if now_s < order[i][0]:
        now_s = order[i][1]
        ans -= 1

print(ans)
```
